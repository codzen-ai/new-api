# 分组价格说明

面向终端用户。本文说明你的价格由什么决定、在哪里看到属于你的价格、以及怎么在账单里核对。

**调用方式不受影响。** 模型名、接口、参数都没有变化，你不需要为此改任何代码。变化只发生在价格上。

## 你的价格由分组决定

你的账号属于某个**分组**。分组决定你调用模型的价格。

同一个模型，不同分组的价格可以不一样。这有两种情况：

1. **整组折扣** —— 你的分组对所有模型统一打折。
2. **单个模型的专属价** —— 你的分组对某几个模型有单独定的价格，其他模型不受影响。

第二种是较新的能力。它的效果是：某个模型对你可能特别便宜（或者是另一个价位），
而同分组的其他模型仍按整组折扣走。

需要注意的是，**当一个模型对你的分组有专属价时，整组折扣对这个模型不再生效**——
专属价就是最终价格，不会在它基础上再打折。你在定价页看到的数字已经是最终结果，不用自己换算。

## 在模型广场查看自己的价格

打开**模型广场**（定价页），你看到的价格已经按你的可用分组算好了。

### 默认显示：你能拿到的最低价

不做任何筛选时，每个模型卡片显示的是**你所有可用分组里的最低价**。
如果你只有一个分组，那就是你的价格；如果你有多个可用分组，显示的是其中最便宜的那个。

### 筛选分组：看某个分组的确切价格

侧边栏可以按分组筛选。选中某个分组后，列表显示的就是**那个分组**的价格。
有多个可用分组时，用这个方式逐个对比。

### 模型详情：分组价格对照表

点开模型详情，可以看到该模型在你各个可用分组下的价格对照，包括输入价、输出价，
以及缓存、音频等派生价格（如果该模型支持）。

> 你只能看到自己可用分组的价格。其他分组的价格不会展示。

## 哪个分组用于计费

按以下优先级：

1. **令牌指定的分组** —— 如果你创建 API 令牌时给它指定了分组，用这个。
2. **账号分组** —— 否则用你账号所属的分组。

所以同一个账号下，指定了不同分组的两个令牌，调用同一个模型可能是不同的价格。
在模型广场用分组筛选功能对比，就能提前知道差多少。

如果你的令牌用的是**自动分组**，系统会在可用分组中按配置的顺序选择，
最终生效的分组会记录在账单里。

## 在账单里核对

**日志 → 点开某条记录的详情**，可以看到这次调用的计价明细：

| 字段 | 含义 |
|---|---|
| 输入 / 输出 | 该次调用实际适用的单价（每百万 token） |
| 模型倍率 | 计价用的模型倍率 |
| 分组倍率 | 计价用的分组倍率 |
| 分组 | 本次计费使用的分组 |

### 看到「分组倍率 1.00x」是正常的

如果这个模型对你的分组有专属价，账单里的**分组倍率会显示 `1.00x`**，
而**模型倍率显示的就是那个专属价**。

这不是折扣没生效，而是专属价已经是最终价格、不再叠加整组折扣的正常表现。
实际扣费以「输入 / 输出」两行显示的单价为准，那就是你真正付的钱。

举个例子。假设某模型的通用倍率是 10，你的分组整体八折，而该模型对你的分组定了专属倍率 5：

| 账单字段 | 显示 |
|---|---|
| 模型倍率 | 5.00 |
| 分组倍率 | 1.00x |

最终按 5 计价，而不是 10 × 0.8 = 8，也不是 5 × 0.8 = 4。

## 常见疑问

**我需要改调用代码吗？**

不需要。模型名、接口地址、请求参数都不变。

**为什么模型广场显示的价格和我上次看的不一样？**

价格由管理员配置，可能调整。以模型广场当前显示的价格为准；已经产生的账单不会被追溯修改。

**为什么我看到的价格和同事不一样？**

你们大概率在不同分组，或者令牌指定了不同分组。

**列表里的价格是最低价，我实际用的时候会是这个价吗？**

只有当你的令牌用的正是那个最便宜的分组时才是。用侧边栏按分组筛选，
或者点开模型详情看分组对照表，能确认具体分组的价格。

**有些模型好像不受分组专属价影响？**

是的。按次计费的模型（比如部分绘图、视频类）和按用量表达式计费的模型，
走的是另一套定价方式，不适用模型级的分组专属价。这类模型的价格同样在模型广场上标明，
以页面显示为准。

**我能看到别的分组的价格吗？**

不能。定价页只返回你可用分组的价格。
